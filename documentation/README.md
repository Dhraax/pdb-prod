# PDB Documentation

This directory is the canonical documentation index for Puerta de Baldur.
Documentation is organized by project module. Except for this index, documents
must live under `documentation/<module>/` and be linked from that module's
`README.md`.

## Modules

| Module | Scope |
|--------|-------|
| [NWScript](nwscript/README.md) | NWScript conventions, templates, caster-level rules, spell eligibility, Use Magic Device behavior, and the Warlock invocation model |
| [Pending changes](pending-changes/README.md) | Reviewed proposals that must not be implemented until explicitly approved |
| [Repository](repository/README.md) | Local Git remote ownership and push-safety policy |

New build, runtime, content, persistence, or gameplay-system documentation
must receive its own clear module directory when that work begins. Do not mix
unrelated systems in the same module merely to avoid creating an index entry.

# Legacy Oficio Resources

replacement is validated.

and must never be used as evidence of current runtime behavior:

- `pb_mod_activate-oficio-viejo.nss` is the retired activation script snapshot;
- `sapo_mesa_mar001.utp.json` is the retired station blueprint snapshot.

Current CNR source lives under `src/cnr/`, with shared activation integration
documented by [`../cnr/README.md`](../cnr/README.md).
